# 第三方来源与许可

本项目在 Chem-PDF-Extractor 上改造生物实验提取和数据库查询，保留包名 `chem-pdf-extractor` 和版本 `0.4.0`。

| 来源 | 本项目实际使用的部分 | 版本定位 | 许可 |
| --- | --- | --- | --- |
| [Chem-PDF-Extractor](https://github.com/myklovenyzforever/chem-pdf-extractor) | 本地网页、PDF 解析、模型调用、字段配置、导出与暂停恢复；源码已提升到根目录并修改 | `c7395658b23730edf391ed5a00d871da6e2102af` | MIT，见根目录 `LICENSE` |
| [LLM-TPD-Extraction](https://github.com/yaochenr/LLM-TPD-Extraction) | 借鉴实验记录与提示词设计；参考提示词在 `vendor/tpd-reference/prompts/`；不运行 PROTAC 专用管线 | `80606e50cf8cb66ab6268178ef29e23735ffb368` | MIT，见 `vendor/tpd-reference/LICENSE` |
| [Google DeepMind science-skills](https://github.com/google-deepmind/science-skills) | PubChem、ChEMBL、PubMed 三个原始 Python 包装脚本，使用项目虚拟环境调用 | 下载时观察到的 main：`4de6786171f1479026da5d3a00f110703c8ba35e` | Apache-2.0，见 `vendor/science-skills/LICENSE` |
| [3Dmol.js](https://github.com/3dmol/3Dmol.js) | 本地页面渲染 PubChem 返回的 3D SDF；静态文件在 `chem_pdf_extractor/static/` | `2.5.5` | BSD-3-Clause，见 `chem_pdf_extractor/static/3Dmol-LICENSE.txt` |
| [RDKit](https://www.rdkit.org/) | PubChem 没有 3D 时，根据确认 CID 的化学结构生成 ETKDGv3 构象，检查分子图和立体化学 | Python 包固定 `2026.9.1`，安装在原 `SenoMiner_AI` 环境；同时新增 Pillow `13.0.0` | BSD-3-Clause，随安装包分发 |

完整来源记录和下载文件哈希见 [upstream-sources.json](upstream-sources.json)。三个数据库脚本保持下载时的内容；整份重复仓库已删除。这些 skills 作为本项目依赖保存在 `vendor/`，没有安装成全局 Codex skills。

Science Skills 的原始使用条款说明保存在 `vendor/science-skills/SKILL_LICENSES.md`。数据库数据和论文全文还适用各自的许可与引用要求：[PubChem](https://pubchem.ncbi.nlm.nih.gov/docs/citation-guidelines)、[ChEMBL](https://chembl.gitbook.io/chembl-interface-documentation/about)、[PubMed](https://pubmed.ncbi.nlm.nih.gov/disclaimer/)。具体论文以其页面标注的全文许可为准。

化学结构来自 [PubChem PUG REST](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest)；3D 坐标优先使用 PubChem 构象，否则用 [RDKit 的 ETKDG](https://www.rdkit.org/docs/GettingStartedInPython.html) 本地生成，页面分别标注来源。模型 ID 参照[火山方舟模型列表](https://docs.volcengine.com/docs/ark/model-list)，云端服务本身不包含在仓库中。文献精读项目与备份代码的取舍见 [开发说明第 7 节](开发说明.md#7-文献精读项目和备份逻辑的取舍)；这些参考未整体安装，也未复制其源代码。
